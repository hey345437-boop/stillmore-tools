# Stillmore Tools

Practical tools for working with images, videos, and social content, from [Stillmore](https://stillmore.studio/).

> **Status: preparing the first release.** This public repository currently contains project information only. Tool source code will be published after development is complete and the tools are ready to share. There are no installable packages or downloadable tool releases yet.

## About Stillmore

Stillmore turns a business's existing photos into ready-to-post social media videos and images. These tools will focus on useful, specific tasks in media preparation and content workflows.

- [Stillmore website](https://stillmore.studio/)
- [Existing online tools](https://stillmore.studio/tools)
- [Tutorials](https://stillmore.studio/tutorials)

The online tools linked above are available separately. Their source code is not included in this repository.

## What to expect

Each tool released here will include:

- A clear description of the problem it solves and who it is for.
- Working source code and setup instructions.
- Example inputs and outputs, with known limitations.
- An explicit license and any required third-party notices.

The first tool and release date have not been announced. Licensing will be specified with the source release.
