# Stillmore Trend Scout

**别再刷半天找灵感。让 AI 每天带着参考视频和脚本来找你。**

把这套工作流交给具备本地工具、联网和视频阅读能力的 AI：发现近期电商短视频，核实数据、观看原片、拆解创意，再交付适合你自己商品的原创复刻脚本。

[English](README.md) · [真实简报样例](docs/example-brief.md) · [每日定时部署](references/scheduling.md) · [Stillmore](https://stillmore.studio/)

## 每次交付什么

- **原视频链接与数据**：来源、发布时间、时长、公开播放量和观测时间。
- **创意拆解**：开场钩子、带时间点的画面依据、值得借鉴的表达方法。
- **原创复刻脚本**：适合的商家、所需素材、逐镜时间、画面动作、字幕、声音和 CTA。
- **可直接使用的简报**：HTML 页面、脚本复制按钮、Markdown 文件。
- **明确的筛选记录**：哪些视频入选、哪些不达标、哪些来源暂时不可用。

## 怎么用

```bash
git clone https://github.com/hey345437-boop/stillmore-tools.git
cd stillmore-tools
```

需要 Python 3.10+。采集器和报告生成器使用标准库；AI 宿主还需要执行命令、联网及查看视频或视频帧的能力。

在 AI 中打开项目目录，发送：

> 阅读本项目的 SKILL.md，完整执行一次电商视频研究：采集最新数据，观看每条入选原视频，输出原链接、创意拆解与原创复刻脚本，生成本地 HTML 和 Markdown 简报并返回路径。遵守配置的筛选条件，无法观看的原片标记为不可分析。

手动跑通后，在 AI 宿主的定时任务功能里设置每天执行完整 Skill。**下载项目不等于开启定时；只执行采集脚本也不会自动完成拆解。** [定时说明](references/scheduling.md)包含可复制的任务指令。

## 筛选标准

| 条件 | 默认设置 |
| --- | --- |
| 发布时间 | 最近 **7 天（168 小时）** |
| 原片时长 | **1–59 秒** |
| 公开播放 | **严格大于 10,000** |
| 排序 | 最近 12 小时的视频优先，组内按播放量降序 |
| 每轮审阅 | 最多 **5 条** |
| 时区 | `Asia/Shanghai` |

这是一套寻找高播放电商创意的研究门槛。没有账号基线对比、销量验证或“必爆预测”。播放增量可在多次观测后计算，目前不参与排序。每天结果数量会变化，零结果时也会交付覆盖报告。

来源包含 **28 个 YouTube 品牌频道 + 18 个 RSS 发现源**。YouTube 自动采集原片数据；TikTok、Instagram 目前通过新闻源发现线索，尚无直接平台指标接口。订阅源只提供有限的近期内容，不能保证覆盖全部七天的视频。

## 和 Stillmore 的关系

**Trend Scout 帮你找到下一条视频的方向；[Stillmore](https://stillmore.studio/)帮助你把已有商业照片变成社交内容。**

研究工具可以独立使用，不要求注册或购买 Stillmore。仓库不包含 Stillmore 网站源码，也没有自动生成成片的产品接口集成。
